# Alberto Watch Company - eProject (demo)

Single-Page-Application, responsive website for Alberto Watch Company.

## How to run
Open `index.html` in Chrome, Edge, Firefox or Safari. No installation needed.

## Files
- index.html - page structure (all sections in one page)
- css/style.css - styling, responsive layout, dark mode colours
- js/script.js - menu switching with fade, product list, search, popup, price list, gallery, form validation, visitor count, ticker
- data/watches.json - the 120 watches as JSON (reference copy of the data in script.js)

## Assumptions
- Watch images are generated SVG illustrations. Replace with real photos in an images/ folder if required.
- Visitor count is stored in the browser (localStorage).
- Location in the ticker needs browser permission; otherwise the time zone is shown.
- Contact form is a demo; nothing is sent.
